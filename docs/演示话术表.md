# 展台 / 实验室演示话术表

目标：不依赖联网，本地 KWS + FAQ + 动作解析即可完成一轮完整演示。  
启动：`source .venv_online/bin/activate && bash scripts/run_voice_wake.sh`

## 固定参数（已写入启动脚本 / env）

| 项 | 值 |
|----|-----|
| 麦 | UGREEN `hw:CARD=MICCM581,DEV=0`，48k/2ch，`channel_0` |
| 唤醒 | 两级 `high=0.35` / `low=0.15` |
| 会话 | `VOICE_SESSION_TIMEOUT_SEC=60`（展会可改 15） |
| 机器人动作 | 演示前确认 `VOICE_ENABLE_ROBOT_COMMAND`（默认 0=只解析不执行） |

## A. 必过话术（演示主线，建议按序）

| # | 你说 | 期望行为 | 通过 |
|---|------|----------|------|
| 1 | **小西小西** | 高/低阈值唤醒 → TTS「我在」 | ☐ |
| 2 | **你是谁** / **做个自我介绍** | 本地 FAQ，短介绍（勿再喊唤醒词） | ☐ |
| 3 | **你能做什么** | 本地能力说明 + 示例指令 | ☐ |
| 4 | **你有几个关节** | 「左右各六个，一共十二个」 | ☐ |
| 5 | **你有什么技术** | 三大技术短答 | ☐ |
| 6 | **右臂向上十厘米** | 本地动作 `move_cartesian` +「好的，正在执行」 | ☐ |
| 7 | **右臂向下十厘米** | 同上，z 为负 | ☐ |
| 8 | **左臂向前五厘米** | 本地动作 | ☐ |
| 9 | **右臂关节三旋转三十度** 或 **右臂第四关节旋转二十度** | 本地 `move_joint` | ☐ |
| 10 | **左臂关节三旋转六十度** | 本地关节 | ☐ |
| 11 | （可选）**右臂向后五厘米左臂向前五厘米** | 双动作数组 | ☐ |
| 12 | **小西小西**（会话中再说一次） | 只回「我在」，不当胡言乱语 | ☐ |
| 13 | **再见** / **退出** | 结束连续会话，回等待唤醒 | ☐ |

**主线通过标准：** 1～10 与 12～13 在安静实验室连续两轮无致命失败（偶发 ASR 错可重说一次）。

## A2. 装配演示（两步分离，需开执行开关）

演示前确认：

```bash
export VOICE_ENABLE_ROBOT_COMMAND=1
# 或单独：export VOICE_ENABLE_ASSEMBLY=1
```

| # | 你说 | 期望行为 | 通过 |
|---|------|----------|------|
| 1 | **小西小西** | 唤醒 →「我在」 | ☐ |
| 2 | **开始拍照** / **开始装配** / **准备装配** | 启动 conda `6d` 下 `gemini_detector`；完成后 TTS「拍照完成，可以开始下一步的装配指令了」 | ☐ |
| 3 | **给我装配两个**（也可用：装配3个 / 组装五个） | 发布 `/assembly_count`（Int32，阿拉伯数字）并启动 `auto_demo`；TTS「好的，开始装配N个」 | ☐ |

**注意：**

- **必须带明确个数**才执行装配；「请装配 / 现在装配 / 给我装配 / 装配一下」不默认 1、不执行。
- 未拍照就说装配数量 → 提示「请先说开始拍照…」，不启 `auto_demo`。
- 「精密装配 / 能装配吗」走介绍 FAQ，不启装配。
- 当前 `auto_demo` 可能仍「识别几个抓几个」；语音侧已预留 `/assembly_count`，后续 C++ 恢复订阅即可对接。

## C. 不建议现场演示的问法

| 避免 | 原因 |
|------|------|
| 很长闲聊、旁边人聊天 | 会被环境人声过滤或拖长 VAD |
| 只说「右臂」 | 澄清句，无动作 |
| 缺手臂的「关节三旋转三十度」 | 需带左臂/右臂 |
| 实时新闻/天气 | 尚未开联网 |

## D. 演示脚本（约 90 秒口述）

```text
1. （站正前 0.5～1 m）小西小西
2. 你是谁
3. 你能做什么
4. 你有几个关节
5. 右臂向上十厘米
6. 左臂关节三旋转三十度
7. 右臂向下十厘米
8. 再见
```

旁白可说：「唤醒一次后，一分钟内可连续对话，无需反复喊名字。」

## E. 失败时快速对照

| 现象 | 先查 |
|------|------|
| 不唤醒 | 距离/音量；日志是否有 `一级唤醒` / `二级拒绝` |
| 唤醒后无反应 | 是否在 cooldown；是否说了话 |
| 总说「请说明左臂还是右臂」 | 指令是否缺臂名/单位；看是否 `本地动作解析命中` |
| 长杂音被录进 | 已限制单段约 6s；说完稍停顿 |
| 「不属于控制范围」 | 应被本地笑话/唱歌/能力类接住；若仍出现则未走本地规则 |
| 改代码后启动 stale | 同步 `install_online` 或 `setup_voice_wake.sh` |

## F. 一键自检（开发机）

```bash
cd /mnt/ssd/voice_online
source .venv_online/bin/activate
python - <<'PY'
import sys
sys.path.insert(0, "scripts")
from voice_local_knowledge import repair_asr_text, match_local_reply
from voice_llm_client import check_simple_action_command, check_local_reply_command
from voice_wake_runtime import is_wake_ack_only, is_session_end_phrase

demo = [
    "小西小西", "你是谁", "做个自我介绍", "你能做什么", "你有几个关节",
    "你有什么技术啊", "给我讲个笑话", "唱首歌",
    "右臂向上十厘米", "左臂向前五厘米", "右臂关节三旋转三十度",
    "左左臂向前移动五厘米", "改着改着又改回来了左臂第三关节旋转六十度",
    "再见", "退出",
]
for s in demo:
    r = repair_asr_text(s)
    wake = is_wake_ack_only(r)
    end = is_session_end_phrase(r)
    act = check_simple_action_command(r)
    faq = check_local_reply_command(r)
    tag = "WAKE" if wake else ("END" if end else ("ACT" if act else ("FAQ" if faq else "MISS")))
    print(f"[{tag:4}] {s!r} -> {r!r}")
PY
```

期望：除特例外均为 `WAKE` / `END` / `ACT` / `FAQ`，不应大片 `MISS`。
