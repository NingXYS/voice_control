# 单臂按摩机器人演示话术表

目标：用本地唤醒、知识问答和按摩流程控制完成一轮安全演示。

## 基础问答

| 你说 | 期望行为 |
|---|---|
| 小西小西 | 唤醒并回复“我在” |
| 你是谁 | 介绍“小西，单臂按摩机器人” |
| 你能做什么 | 说明按摩流程、通用知识问答与联网搜索能力 |
| 你有几条手臂 | 回复一条手臂 |
| 你有几个关节 | 回复六个关节 |
| 方向接口完成了吗 | 明确回复接口已预留、真实控制端尚未接入 |

## 按摩流程

真实机械臂运行前必须确保现场有人监护，周围环境安全，并能随时操作实体急停。

| 顺序 | 你说 | 期望行为 |
|---|---|---|
| 1 | 开始记录点位 | 启动拖动示教 |
| 2 | 界面点“记录当前点位”或终端回车 | 按左肩、右肩、背部、左腰、右腰的顺序记录五个点；录满五个点自动结束并构建 |
| 3 | （可选）记录完成 | 若未自动构建，可再说一次以保存并构建 |
| 4 | 按摩状态 | 回复当前状态和按摩点数量 |
| 5 | 开始按摩左肩，轻一点 | 复述左肩和轻一点（30 牛），只进入等待安全确认，不立即运动 |
| 6 | 确认开始 | 确认现场安全后启动按摩，并从 `massage_music/` 随机播放背景音乐 |

必须恰好记录五个按摩点：左肩、右肩、背部、左腰、右腰。安全位由下层程序固定，不参与示教。构建失败或点位数量不正确时，上一份有效方案保持不变。

一条启动指令可以选择一个、多个或全部位置。力度可选很轻、轻一点、适中、重一点、很重，也可以说一至五级或档，分别对应 20、30、40、50、55 牛。

## 联网和娱乐

| 你说 | 期望行为 |
|---|---|
| 上海今天天气怎么样 | 联网查询上海实时天气 |
| 北京明天天气 | 查询北京次日预报 |
| 今天天气怎么样 | 查询 `VOICE_DEFAULT_CITY` 配置的城市 |
| 搜索一下今天的机器人新闻 | Dify 使用模型原生联网搜索，并播报简短摘要 |
| 今天是多少号 | 按北京时间回答当前日期 |
| 还有多少天国庆节 | 联网确认当前日期并回答节日倒计时 |
| 为什么天空是蓝色的 | 直接回答一般科学知识 |
| 给我讲个笑话 | 播报一条本地安全笑话 |
| 唱首歌 | 用普通 TTS 朗读一小段原创歌曲，不模拟真实歌声 |

通用问答和搜索使用 Dify 模型原生联网，不需要额外搜索 API Key；所选模型必须支持联网搜索，并在“通用问答与联网搜索”节点将开关设为 `True`。未说明天气城市时使用工作流环境变量 `DEFAULT_WEATHER_CITY`。联网内容只用于生成语音回答，不会进入机械臂控制链路。

## 上下左右预留接口

以下指令现在能够在本地解析，但真实适配器未接入时只回复识别结果，不执行机械臂运动：

- 按摩机械臂向上五厘米
- 按摩机械臂向下五厘米
- 按摩机械臂向左三厘米
- 按摩机械臂向右三厘米

方向指令必须包含方向、数值和单位。不能只说“向上一点”，系统不会猜测默认距离。

待控制 SDK 完成后，实现 `MassageMotionInterface.move_relative(direction, distance_m)` 并注入 `MassageController` 即可。适配器必须负责工作空间限位、碰撞检测和底层执行结果。

## 安全边界

- 当前没有语音停止正在执行的按摩。
- 任何不适或危险都应立即使用实体急停。
- 包含位置和力度的“开始按摩”指令之后仍需“确认开始”，防止误触发。
- 上下左右接口未接入时，返回结果中的 `started` 为 `false`、`implemented` 为 `false`。
- 原有 `move_cartesian`、`move_joint` 和 ROS 发布代码保留为兼容控制链路，不等同于新按摩方向接口已完成。
